# Steam Booster Value Optimizer

Steam 卡牌补充包价值优化工具 — 找出最划算的宝石兑换组合。

## 功能

- 输入 Steam 公开 ID，自动获取账户游戏列表
- 查询每个游戏的卡牌补充包兑换所需宝石数
- 查询 1000 宝石袋市场价格（人民币）
- 计算每款游戏的：宝石成本(¥) vs 卡牌总价值(¥)
- 按回报率/利润排序，找出最值得兑换的游戏

## 安装

```bash
pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

然后打开 http://127.0.0.1:8000

## 使用方法

1. 在输入框输入你的 Steam ID（公开账户）
2. 点击"查询"
3. 查看按回报率排序的游戏列表
4. 绿色行 = 盈利游戏，卡牌价值 > 宝石成本

## 注意

- Steam ID 必须设置为**公开**，否则无法获取游戏列表
- 价格数据来自 Steam 市场和 SteamGridDB，可能有延迟
- 宝石价格实时波动，计算结果仅供参考
